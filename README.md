# eviltycoon — Town Hunter

Prototype game quản lý thị trấn + hunter tự săn (TypeScript, Three.js).

- `game/` — client và simulation core. Hướng dẫn chạy: [game/README.md](game/README.md).
- `TECH_SPEC.md` — kiến trúc, AI hunter, data schema, lộ trình M0–M7.
- `TODO.md` — việc chưa làm và lỗi/cân bằng cần sửa.
